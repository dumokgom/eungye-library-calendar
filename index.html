          서버 코드(Code.gs) 적용 방법

          서버 코드를 고친 뒤에는 아래 순서로 다시 배포해야 반영돼요. 웹 앱 주소는 바뀌지 않아요.

          1. 아래 Code.gs 복사 버튼을 누릅니다.
          2. 설정이 저장된 구글 시트에서 확장 프로그램 → Apps Script를 엽니다.
          3. 왼쪽 Code.gs의 내용을 모두 지우고 붙여 넣은 뒤 저장(💾)을 누릅니다.
          4. 오른쪽 위 배포 → 배포 관리를 누릅니다.
          5. 지금 배포 옆 연필(수정)을 누르고, 버전에서 새 버전을 고른 뒤 배포를 누릅니다.
          6. 이 화면을 새로 고침합니다. 이 안내가 접혀 있으면 적용된 거예요.
