# 홈페이지 · 대출반납일력표 저장 서버 설정 방법 (구글 시트 + Apps Script)

로그인 없이 누구나 홈페이지와 일력표를 보고, PIN을 아는 사람만 관리자 화면에서 저장할 수 있게 하는 설정입니다. 처음 한 번만 하면 됩니다. (약 10분)

## 1. 구글 시트 만들기
1. 도서관 운영용 구글 계정으로 https://sheets.new 를 엽니다.
2. 시트 이름을 `은계파크자이 일력표 설정` 처럼 알아보기 쉽게 바꿉니다.

## 2. 스크립트 붙여 넣기
1. 시트 메뉴에서 **확장 프로그램 → Apps Script** 를 엽니다.
2. 왼쪽 `Code.gs` 의 내용을 모두 지우고, 이 폴더의 [Code.gs](Code.gs) 내용을 통째로 붙여 넣습니다.
3. 저장(💾) 버튼을 누릅니다.
4. 위쪽 함수 선택 칸에서 `setup` 을 고르고 **실행** 을 누릅니다.
   - 처음 실행할 때 권한 승인 창이 뜹니다. 내 계정을 선택하고 허용해 주세요.
   - "Google에서 인증하지 않은 앱" 경고가 나오면, 빨간 상자 안의 밑줄 링크 **(프로젝트 이름)(안전하지 않음) 앱으로 이동** 을 누르면 됩니다. 예전 화면에서는 **고급** 버튼을 누른 뒤 나오던 링크입니다. 개발자 칸에 내 구글 계정이 표시되는지 확인하세요. 내가 만든 스크립트라서 나오는 안내입니다.
   - 실행하기 전에 Apps Script 왼쪽 위 '제목 없는 프로젝트'를 눌러 `일력표 저장 서버` 처럼 이름을 바꿔 두면 알아보기 쉽습니다.
   - 시트에 `설정` 탭이 생기고 기본값(대출 7일, 일요일 휴관, 공휴일)이 들어갑니다.

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
2. 유형 선택(톱니바퀴)에서 **웹 앱** 을 고릅니다.
3. 다음처럼 설정합니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** 를 누르고, 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 을 복사합니다.

## 4. 홈페이지와 일력표에 주소 넣기
[index.html](../index.html) 과 [calendar/index.html](../calendar/index.html) 두 파일을 열어 `<script>` 바로 아래 줄을 찾습니다.

```js
const API_URL = "PASTE_APPS_SCRIPT_WEB_APP_URL_HERE";
```

따옴표 안을 3번에서 복사한 주소로 바꾸고 저장합니다. (이 주소는 Claude에게 알려주시면 대신 넣어 드립니다.)

## 5. 웹에 올리기
저장소 전체(`index.html`, `calendar/`, `assets/`, `apps-script/`)를 올립니다. 예: GitHub Pages, Netlify Drop(https://app.netlify.com/drop 에 파일을 끌어다 놓기), 또는 지금 쓰시는 호스팅.

> Claude 아티팩트 주소(claude.ai/artifact/…)에서는 외부 서버 연결이 막혀 있어 이 방식이 동작하지 않습니다.

## 사용 방법
- 일력표 화면: 1분마다 서버에서 최신 설정을 가져옵니다. 인터넷이 끊겨도 마지막으로 받은 설정으로 계속 표시합니다.
- 관리자: 화면 아래 **관리자** → PIN 입력 → 수정 후 저장. PIN은 서버에서 확인합니다.
- 처음 PIN은 **1234** 입니다. 바로 바꿔 주세요.
- PIN을 10분 안에 10번 틀리면 10분 동안 잠깁니다.
- PIN을 잊어버리면: Apps Script 편집기 → **프로젝트 설정(톱니바퀴) → 스크립트 속성** 에서 `PIN_HASH` 를 삭제하면 1234로 돌아갑니다.

## 스크립트를 고친 뒤에는 (예: 홈페이지 기능이 추가된 서버 버전 2로 올릴 때)
1. 홈페이지 관리 화면(`…/#admin`)의 **Code.gs 복사** 버튼을 누르거나, 이 폴더의 [Code.gs](Code.gs) 내용을 복사합니다.
2. 구글 시트 → **확장 프로그램 → Apps Script** 에서 `Code.gs` 내용을 모두 지우고 붙여 넣은 뒤 저장합니다.
3. **배포 → 배포 관리 → (연필) 수정 → 버전: 새 버전 → 배포** 를 누릅니다. 웹 앱 주소는 그대로 유지됩니다.
4. 홈페이지 관리 화면을 새로 고쳐 "서버 업데이트가 필요해요" 안내가 사라졌는지 확인합니다.

- 기존 설정(대출 기간, 휴관일, 오늘만 수정, PIN)은 그대로 유지됩니다.
- 홈페이지 내용(일정, 공지, 새 책, 프로그램, 봉사자 모집)은 같은 `설정` 탭 A1 칸에 함께 저장됩니다.

## 봉사자 "열었어요 / 닫았어요"
- 휴대폰에서 `…/#open` 을 열고 PIN을 넣은 뒤, 도착하면 **몇 시까지** 고르고 **열었어요**, 떠날 때 **닫았어요** 를 누릅니다.
- 고른 시각이 지나면 홈페이지는 저절로 "열려 있어요"를 멈춥니다. 닫기를 잊어도 밤새 열린 것으로 보이지 않습니다.
- 도서관 기기에서는 "이 기기 기억하기"를 켜 두면 PIN을 다시 묻지 않습니다. 개인 휴대폰에서는 켜지 마세요.
